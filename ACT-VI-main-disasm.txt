;   Defect 2 - Synthetic harvest (implant_tick, implant_stage_write inlined)
;     VA 0x1000A328  file 0xA328
;       d03d  beq.n 0x1000A3A6   ; correct: harvest gate clear, nothing staged
;     COMPROMISE: patch byte 0xA329 0xD0 -> 0xD1 (beq -> bne)
;     The harvest gate is inverted, so each interval tick appends a synthetic
;     delivery record to the staging ring buffer.
;
;   Defect 3 - Staging marker (implant_init, implant_infect inlined)
;     VA 0x1000A5CE  file 0xA5CE
;       b1d9  cbz r1, 0x1000A608   ; correct: marker gate clear, no write
;     COMPROMISE: patch byte 0xA5CF 0xB1 -> 0xB9 (cbz -> cbnz)
;     The marker gate is inverted, so the first boot erases and programs marker
;     0xC7 into 0x103FF000. The copy inlined into implant_handle_command stays
;     gated.
;
;   Defect 4 - UNLOCK authorization (control_handle_frame)
;     VA 0x1000757C  file 0x757C
;       b128  cbz r0, 0x1000758A   ; correct: authorization failed, reject
;     COMPROMISE: patch byte 0x757D 0xB1 -> 0xB9 (cbz -> cbnz)
;     The authorization verdict is inverted, so an unauthenticated or replayed
;     UNLOCK envelope reaches the applied command and package.
;
; The CoreDebug DHCSR anti-debug check is identical in both images and is an
; analysis obstacle, not a patch.
;
; The reserved-sector marker is written with the Pico SDK flash API

; so the marker persists on real flash.
;
